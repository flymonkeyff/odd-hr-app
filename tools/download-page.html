이 파일들은 검증을 통과했습니다

    아이폰 · 아이패드 설치 없음

    1. Safari로 이 주소의 앱을 엽니다.
    2. 아래쪽(아이패드는 위쪽) 공유 버튼 → 홈 화면에 추가를 누릅니다.
    3. 홈 화면의 ODD HR 아이콘으로 엽니다. PC에서 코드로 들어왔다면 PC 앱의 설정 → 이메일 연결을 먼저 하고, 여기서는 이메일로 로그인으로 들어오세요.

    앱 화면 파일은 모두 해시(SRI)로 묶여 있어, 한 글자라도 바뀌면 열리지 않습니다.

    앱 열기

    Windows

    설치 파일을 실행하면 바로 설치되고 시작 메뉴와 설정 → 앱 → 설치된 앱에 등록됩니다. 처음 한 번 "PC 보호" 창이 뜨면 추가 정보 → 실행. 그다음부터는 앱을 켤 때 자동으로 업데이트되며 경고가 다시 뜨지 않습니다.

    Mac

    dmg를 열고 ODD HR을 응용 프로그램으로 끌어다 놓으면 Launchpad에 뜹니다. 칩은 애플 메뉴 → 이 Mac에 관하여의 "칩" (M1~M4면 Apple 실리콘). 처음 열 때 막히면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기. 그다음부터는 켤 때 자동으로 업데이트됩니다.

    받은 파일 확인하기

    받은 파일을 여기에 끌어다 놓으면 이 컴퓨터 안에서 지문(SHA-256)을 계산해 위 값과 비교합니다. 파일은 어디로도 보내지 않습니다.

    터미널로 직접 확인하기 
    Windows (PowerShell):  Get-FileHash .\파일이름 -Algorithm SHA256
Mac (터미널):           shasum -a 256 ~/Downloads/파일이름

    나온 값이 위 파일의 SHA-256과 같으면 온전한 파일입니다. 전체 목록: SHA256SUMS.txt
