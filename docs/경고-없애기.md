# "위험한 프로그램" 경고 없애기

## 왜 뜨나
Windows SmartScreen과 Mac Gatekeeper는 인터넷에서 받은 프로그램에 **누가 만들었는지 확인된 서명**이 없으면 경고를 띄웁니다.
ODD HR은 아직 서명 인증서 없이 배포되고 있어서 처음 설치할 때 경고가 뜹니다. 프로그램에 문제가 있다는 뜻은 아닙니다.
(릴리스의 SHA256SUMS.txt로 파일이 바뀌지 않았는지는 확인할 수 있습니다.)

## 0.3.0에서 이미 해결한 것
| 문제 | 0.3.0 |
|---|---|
| 업데이트할 때마다 다시 받아 깔아야 함 | 앱을 켤 때 새 버전을 확인하고, 지문(SHA-256)이 맞을 때만 설치한 뒤 다시 켭니다 |
| 업데이트할 때마다 경고 | 앱이 직접 받은 파일에는 '인터넷에서 받은 파일' 표시가 붙지 않아 **첫 설치 뒤로는 경고가 다시 뜨지 않습니다** |
| Windows '설치된 앱'에 안 보임 | `ODD-HR-Setup-0.3.0.exe`(설치 파일)가 설치된 앱·시작 메뉴·바탕화면에 등록합니다. zip으로 쓰던 분은 설정 → 업데이트 → **제대로 설치하기** |
| Mac 응용 프로그램에 안 보임 | dmg를 열어 '응용 프로그램'으로 끌어다 놓습니다. 다른 곳에서 켜면 앱이 응용 프로그램 폴더로 옮길지 묻습니다 |

## 첫 설치 경고까지 완전히 없애려면 (유료)
빌드 설정(CI)은 이미 준비되어 있습니다. 인증서를 사서 GitHub 저장소 → Settings → Secrets and variables → Actions 에 아래 값만 넣으면 다음 릴리스부터 서명됩니다.

### Mac — Apple Developer Program (연 USD 99)
- 한국 개인도 가입 가능합니다 (법적 이름, 영문 표기 필요).
- 가입 후 "Developer ID Application" 인증서를 만들어 .p12로 내보냅니다.
- Secrets:
  - `MAC_CSC_LINK` — .p12 파일을 base64로 바꾼 값
  - `MAC_CSC_KEY_PASSWORD` — .p12 비밀번호
  - `APPLE_ID` — Apple 계정 이메일
  - `APPLE_APP_SPECIFIC_PASSWORD` — appleid.apple.com에서 만든 앱 암호
  - `APPLE_TEAM_ID` — 개발자 계정의 팀 ID
- 넣으면 CI가 서명 → Apple 공증(notarize) → 스테이플까지 합니다. Gatekeeper 경고가 사라집니다.

### Windows — 코드 서명 인증서
- **Azure Artifact Signing**(월 $9.99)은 현재 미국·캐나다 개인, 미국·캐나다·EU·영국 단체만 가입할 수 있어 한국 개인은 쓸 수 없습니다.
- **Certum Open Source Code Signing**(€49): 오픈소스 개발자용으로 개인도 신청할 수 있습니다. 저장소를 공개(오픈소스 라이선스)해야 합니다.
  - 이 인증서는 클라우드(SimplySign) 방식이라 .pfx 파일이 없습니다. 쓰기로 하면 CI 서명 단계를 SimplySign용으로 바꿔야 합니다 (말씀해 주시면 바꿔 드립니다).
- **.pfx 파일로 주는 일반 OV 인증서**를 사면 바로 쓸 수 있습니다:
  - `WIN_CSC_LINK` — .pfx를 base64로 바꾼 값
  - `WIN_CSC_KEY_PASSWORD` — .pfx 비밀번호
- 참고: 서명을 해도 SmartScreen은 내려받은 사람이 쌓일 때까지 한동안 경고를 띄울 수 있습니다(평판 방식).

## 그때까지 처음 설치할 때
- **Windows**: "Windows의 PC 보호" → **추가 정보** → **실행**
- **Mac**: dmg에서 응용 프로그램으로 옮긴 뒤 앱을 **우클릭 → 열기 → 열기**. (macOS 15 이후: 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**)
- 한 번만 하면 되고, 그 뒤 업데이트는 자동이며 경고가 뜨지 않습니다.
